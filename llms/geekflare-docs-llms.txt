- [Web Scraping](https://docs.geekflare.com/endpoint/webscraping.md): Fetch a page and return content as Markdown, HTML, JSON, or plain text. Automatically detects whether JavaScript rendering is needed, with optional stealth mode, `proxyMode`-controlled proxy routing, CSS/XPath field extraction, and ready-made `product`/`contact` extraction templates.
- [Search](https://docs.geekflare.com/endpoint/search.md): Structured search results from the web or news. Strips out ads and HTML noise to provide pure data in JSON, Markdown, or HTML. Fully supports AI-grounded answers, search-with-scrape, image search, and targeted Web or News sourcing.
- [Brand](https://docs.geekflare.com/endpoint/brand.md): Retrieve structured brand information for a website domain, including key brand details useful for identifying and understanding a website or company.
- [Meta Scraping](https://docs.geekflare.com/endpoint/metascraping.md): Extract a page's meta tags, Open Graph, and Twitter Card data like title, description, canonical URL, images, and more without scraping the full page body.
- [Screenshot](https://docs.geekflare.com/endpoint/screenshot.md): Capture a pixel-perfect screenshot of any URL as PNG, JPEG, or WebP. Supports full-page capture, device emulation, custom viewports, and CAPTCHA/cookie-banner bypass.
- [DNS Records](https://docs.geekflare.com/endpoint/dns-records.md): Look up A, AAAA, CNAME, MX, CAA, NS, SOA, SRV, and TXT records for any domain. Query every supported type in one call, or pass `types` to fetch only the ones you need.
- [Broken Link Checker](https://docs.geekflare.com/endpoint/broken-link.md): Scan a webpage for broken links and report which URLs return errors, so you can fix dead links before they hurt SEO or user experience.
- [Mixed Content](https://docs.geekflare.com/endpoint/mixed-content.md): Scan an HTTPS page for insecure HTTP resources like images, scripts, or stylesheets that trigger browser security warnings and break the padlock icon.
- [Lighthouse](https://docs.geekflare.com/endpoint/lighthouse.md): Run a Google Lighthouse audit for performance, SEO, accessibility, and best practices, with support for advanced flags via the `parameters` array.
- [Load Time](https://docs.geekflare.com/endpoint/load-time.md): Measure how long a webpage takes to fully load from a real browser. Pass `targetCountries` (up to 3 ISO country codes) to also test reachability from those locations via proxy alongside the default US server test, and compare results side by side.
- [Site Status](https://docs.geekflare.com/endpoint/site-status.md): Check whether a website is reachable and returns a successful HTTP response. Ideal for uptime monitoring and pre-flight checks before running other tests.
- [DNSSEC](https://docs.geekflare.com/endpoint/dnssec.md): Check whether DNSSEC is properly configured and validating for a domain, helping you confirm protection against DNS spoofing and cache poisoning attacks.
- [MTR](https://docs.geekflare.com/endpoint/mtr.md): Run a My Traceroute (MTR) diagnostic between Geekflare and a target host, combining traceroute and ping to show packet loss and latency at each network hop.
- [Ping](https://docs.geekflare.com/endpoint/ping.md): Send ICMP ping requests to a URL or IP and return latency, packet loss, and round-trip time statistics — useful for quick reachability and network health checks.
- [TLS Scan](https://docs.geekflare.com/endpoint/tls-scan.md): Inspect a domain's TLS/SSL configuration, including which protocol versions are supported (from the deprecated and insecure SSLv2/SSLv3 through TLS 1.3) and certificate details, to catch expiring certificates and outdated, insecure configurations.
- [Port Scanner](https://docs.geekflare.com/endpoint/port-scanner.md): Scan a domain or IP for open TCP ports, either across the top N most common ports or a custom range you specify. Useful for surface-level network security audits and exposure checks.
- [URL Redirection Checker](https://docs.geekflare.com/endpoint/url-redirect.md): Trace the full redirect chain of a URL, including every intermediate hop, status code, and the final destination. Useful for auditing SEO redirects and link rot.
- [PDF Generator](https://docs.geekflare.com/endpoint/pdf-generator.md): Convert any URL into a downloadable PDF document, with control over page orientation, margins, and scale. Useful for archiving pages or generating reports.
